## 意见 A：标准应纳入"衍生数据跨主体聚合的等级升级"治理要求（对应 Clause [填写：分级/治理相关章节]）

**实测依据**（三步，均可公开复现）：
1. **数据层**：真实公开电力数据接入（National Grid ESO Carbon Intensity API + OWID，许可声明完整），Asset 级分类分级元数据落库；
2. **策略层**：一般/重要/核心三级 → ODRL Permission/Prohibition/Duty 映射，在 DSP 连接器中真实生效（放行/越权拒绝/聚合升级 duty 三类判定，拦截率 0%→100% 对照实验）；
3. **协议层**：DSP contract negotiation 实测发现——（a）ODRL 缺少聚合升级原生语义（需自定义 leftOperand）；（b）TCK 用例集未覆盖该场景。

**建议条款**：建议标准在治理要求中增加：
- 衍生数据分级遵循"就高从严"，聚合方承担登记与再分类义务；
- 分级结论应支持机器可执行表达（ODRL/等效），并随数据流通协议持续生效。

## 意见 B：治理有效性应配套可量化评测指标

建议标准附录纳入治理成效评测指标集（本项目已在真实日志上验证可测）：越权拦截率、超范围导出拦截率、授权链路可审计率、存证完整率、目录覆盖率、分级准确率、单次评测耗时、新增数据集接入成本。对齐"以评提质/工具化、订单化"的行业方向，使标准可验收、可复测。
